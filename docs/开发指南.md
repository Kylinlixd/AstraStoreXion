# 星辰离子X开发指南

本文档旨在帮助开发者快速了解项目结构、开发流程和贡献方式。

## 快速开始

### 开发环境要求

- Go 1.21+
- Docker & Docker Compose
- 支持Go模块的IDE（推荐VS Code + Go插件或GoLand）
- Git

### 代码获取

```bash
# 克隆仓库
git clone https://github.com/astrastore/astrastore-xion.git
cd astrastore-xion

# 安装依赖
go mod tidy
```

### 本地开发环境启动

```bash
# 启动所有服务（API网关、元数据服务、存储节点）
./scripts/dev-start.sh

# 只启动特定服务
./scripts/dev-start.sh apigateway
./scripts/dev-start.sh metaservice
./scripts/dev-start.sh storagenode

# 停止服务
./scripts/dev-stop.sh
```

### 构建

```bash
# 构建所有组件
make build

# 构建特定组件
make build-apigateway
make build-metaservice
make build-storagenode
```

### 测试

```bash
# 运行所有测试
make test

# 运行单元测试
make test-unit

# 运行集成测试
make test-integration

# 运行特定测试
go test ./test/unit/metadata_service_test.go
```

## 项目结构详解

### 核心模块

- **pkg/api**: 定义了所有服务的Protocol Buffers API
- **pkg/metadata**: 元数据管理，包括文件元数据的CRUD操作
- **pkg/storage**: 存储引擎，负责实际的文件块存储
- **pkg/balance**: 负载均衡，实现一致性哈希和数据分片
- **pkg/raft**: 共识协议实现，基于Hashicorp Raft

### 应用入口

- **core/apigateway**: API网关，负责接收和路由客户端请求
- **core/metaservice**: 元数据服务，管理文件元数据
- **core/storagenode**: 存储节点，提供实际的文件存储服务

### 客户端SDK

- **client/go**: Go客户端实现
- **client/java**: Java客户端实现
- **client/nodejs**: NodeJS客户端实现
- **client/python**: Python客户端实现

### 部署配置

- **deploy/dockerfile**: 各组件的Docker镜像构建文件
- **deploy/mysql**: MySQL数据库初始化脚本
- **deploy/docker-compose.yaml**: Docker Compose配置文件

## 开发规范

### 代码风格

- 遵循Go官方的代码风格和最佳实践
- 使用`gofmt`和`golint`确保代码格式一致
- 所有代码必须通过`go vet`检查

### 提交规范

提交消息格式：

```
<类型>: <描述>

[可选的详细描述]

[可选的关闭issue引用]
```

类型包括：
- `feat`: 新功能
- `fix`: 修复Bug
- `docs`: 文档变更
- `style`: 代码格式变更
- `refactor`: 代码重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建过程或辅助工具变更

例如：
```
feat: 添加文件元数据缓存层

实现了基于内存的文件元数据缓存，提高读取性能。
缓存采用LRU策略，默认容量为1000条记录。

Closes #123
```

### 分支管理

- `main`: 主分支，保持稳定可发布状态
- `develop`: 开发分支，包含最新的开发代码
- `feature/*`: 功能分支，用于开发新功能
- `bugfix/*`: 修复分支，用于修复Bug
- `release/*`: 发布分支，用于准备新版本发布

## API开发

### 添加新API

1. 修改 `pkg/api/fileservice.proto` 文件，添加新的服务定义或消息类型
2. 运行 `make gen-proto` 生成Go代码
3. 在 `core/apigateway/handlers.go` 中实现新的处理函数
4. 在 `core/apigateway/main.go` 中注册新的路由

### API网关工作流程

1. 接收HTTP请求
2. 验证请求参数和权限
3. 调用元数据服务或存储节点服务
4. 处理响应并返回给客户端

## 存储引擎开发

### 存储节点工作流程

1. 初始化本地存储
2. 注册到服务发现系统（Consul）
3. 启动gRPC服务
4. 接收写入/读取/删除块请求
5. 定期发送心跳

### 添加新的存储引擎

1. 在 `pkg/storage` 目录下创建新的实现文件，例如 `s3_storage.go`
2. 实现 `StorageNode` 接口
3. 在 `core/storagenode/main.go` 中添加相应配置和初始化代码

## 元数据服务开发

### 元数据服务工作流程

1. 初始化数据库连接
2. 注册到服务发现系统
3. 启动gRPC服务
4. 处理元数据的CRUD请求

### 添加新的元数据存储

1. 在 `pkg/metadata` 目录下创建新的实现文件，例如 `mysql_metadata.go`
2. 实现 `MetadataService` 接口
3. 在 `core/metaservice/main.go` 中添加相应配置和初始化代码

## 负载均衡开发

### 负载均衡器工作流程

1. 初始化一致性哈希环
2. 监控存储节点状态
3. 根据文件ID选择存储节点
4. 检测热点文件并进行迁移

### 添加新的负载均衡策略

1. 在 `pkg/balance` 目录下创建新的实现文件，例如 `weight_balance.go`
2. 实现 `Balancer` 接口
3. 在相应的使用处添加配置和初始化代码

## Raft共识开发

### Raft节点工作流程

1. 初始化本地状态
2. 连接到现有集群或创建新集群
3. 参与Leader选举
4. 复制日志条目
5. 应用已提交的日志到状态机

### 添加新的共识协议

1. 在 `pkg/raft` 目录下创建新的实现文件
2. 实现 `RaftNode` 接口
3. 在相应的使用处添加配置和初始化代码

## 客户端SDK开发

### 客户端工作流程

1. 初始化配置
2. 连接到API网关
3. 发送上传/下载/删除请求
4. 处理响应和错误

### 添加新语言的客户端SDK

1. 在 `client` 目录下创建新的语言目录，例如 `client/ruby`
2. 实现基本的客户端接口和功能
3. 编写单元测试和示例代码
4. 更新客户端使用文档

## 常见问题

### Q: 如何调试服务?

A: 可以通过以下方式调试:
1. 查看日志: `docker-compose logs -f apigateway`
2. 使用Go调试器: 在IDE中配置远程调试
3. 使用测试脚本: `./scripts/test-api.sh`

### Q: 如何添加新依赖?

A: 使用Go模块添加依赖:
```bash
go get github.com/example/package
```
然后运行:
```bash
go mod tidy
```

### Q: 如何处理错误?

A: 系统采用标准Go错误处理方式:
1. 函数返回错误作为最后一个返回值
2. 调用者负责检查和处理错误
3. 使用`fmt.Errorf`添加上下文
4. 避免使用panic，除非是不可恢复的错误
