# v0.1 File Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a tested, Docker-deployable single-node file service with real upload, download, status, list, and delete behavior.

**Architecture:** The new `pkg/files` application service coordinates a validated local block store and metadata repository. The API gateway becomes a thin HTTP adapter that authenticates requests and delegates to `pkg/files`; it never creates filesystem paths or fabricates file responses.

**Tech Stack:** Go 1.21, Gorilla Mux, Prometheus client, Docker Compose, testify, GitHub Actions.
