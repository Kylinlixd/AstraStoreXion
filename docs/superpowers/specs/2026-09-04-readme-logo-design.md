# AstraStoreXion README Logo 设计

## 目标

为仓库根目录的 `README.md` 增加一个具有品牌辨识度的横幅 Logo。视觉需要同时表达 Astra（星辰）与 Xion（离子）的含义，并在 GitHub 明暗主题中保持稳定、清晰的表现。

## 品牌文字

- Logo 中只出现 `AstraStoreXion`。
- 拼写必须完全准确。
- 不添加中文副标题、口号、徽章或水印。
- `Xion` 使用电光青强调，其余文字使用深紫灰或接近白色的高对比颜色，具体取决于磨砂背景的明度。

## 视觉方案

采用“半透明磨砂舱 + 离子涡旋”的横向组合标识。

左侧品牌图案由以下元素组成：

- 一个半透明玻璃材质的紫色能量核；
- 两到三条交错的椭圆离子轨道，通过前后遮挡表现纵深；
- 五到七颗大小不同的紫色与电光青离子球；
- 球体具有清晰高光、柔和暗部、轻微折射和克制辉光；
- 图形四周保留充足安全留白，不贴边，不被横幅背景压缩。

右侧放置 `AstraStoreXion` 字标。字体风格现代、简洁、略带未来感，但保持良好可读性。图案与字标之间留出明显间距。

## 画布与质感

- 使用约 10:3 的横向画布。
- 整体置于圆角半透明磨砂舱中。
- 背景采用浅紫、淡青与雾白的柔和渐变，只提供轻微空间感，不使用密集星点或复杂宇宙插画。
- 磨砂舱具有轻度透明、玻璃边缘高光和柔和阴影。
- 风格应精致、立体、克制，避免卡通化、霓虹过曝和通用原子图标观感。

## 交付文件

- 使用内置图像生成工具生成最终位图。
- 最终文件保存为 `docs/assets/astrastore-xion-logo.png`。
- PNG 应保持清晰边缘和足够分辨率，适合在 README 中以约 760 像素宽度显示。
- 项目引用的最终文件必须位于仓库内，不依赖工具的默认生成目录。

## README 集成

在根目录 `README.md` 的现有一级标题前加入居中的图片：

```html
<p align="center">
  <img src="docs/assets/astrastore-xion-logo.png" alt="AstraStoreXion logo" width="760">
</p>
```

保留现有 `# AstraStoreXion` 标题及其后全部内容，不改动其他文档结构。

## 验收标准

- 图片文件能从 README 的相对路径正常加载。
- Logo 中的文字只有 `AstraStoreXion`，且拼写正确。
- 左侧图案包含一个玻璃能量核、交错轨道和五到七颗离子球。
- 图案有明确的立体深度，且四周留白充足。
- 磨砂舱呈半透明玻璃质感，背景不会挤压或干扰前景。
- 紫色与电光青配色符合已确认的方向。
- README 原有内容保持不变，仅在顶部增加 Logo。

## 验证方式

1. 检查 PNG 的尺寸、格式和文件位置。
2. 打开生成图片，人工检查构图、文字、透明质感和离子球数量。
3. 检查 README 的图片引用路径与替代文本。
4. 查看 `git diff`，确认没有修改 README 的其他内容。
